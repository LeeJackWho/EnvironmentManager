# 环境管理器 - 配置管理功能

## 🎯 概述

配置管理功能提供了一个统一的界面来管理环境管理器的所有配置项，包括数据库连接、API 密钥、应用设置等。通过可视化界面，您可以轻松配置和验证各种服务的连接。

## 🚀 功能特点

### **📋 配置分类管理**
- **📝 Notion 配置**：API 密钥和数据库连接
- **🤖 Midscene.js 配置**：智能验证码识别服务
- **🛡️ 验证码服务**：OCR 和第三方验证码服务
- **⚙️ 应用配置**：端口、日志级别等基础设置
- **🔒 安全配置**：HTTPS、JWT 等安全相关设置

### **🔍 实时验证**
- **API 连接测试**：实时验证 API 密钥的有效性
- **数据库访问验证**：检查数据库连接和权限
- **配置格式验证**：确保配置值格式正确
- **依赖关系检查**：验证配置项之间的依赖关系

### **💾 安全存储**
- **敏感信息保护**：密码和 API 密钥安全存储
- **配置文件管理**：自动生成和维护 .env.local 文件
- **备份机制**：配置更改前自动备份
- **版本控制友好**：敏感信息不会意外提交到代码库

## 🎮 使用方法

### **访问配置管理**
1. 在侧边栏点击 **"配置管理"** 菜单
2. 或直接访问：`http://localhost:3000/config`

### **配置流程**

#### **1. Notion 配置（必需）**
```
📝 Notion 配置
├── Notion API Key (必需)
│   ├── 从 https://www.notion.so/my-integrations 获取
│   ├── 格式：secret_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
│   └── 支持实时验证
└── Notion 数据库 ID (必需)
    ├── 从数据库 URL 中获取
    ├── 格式：32位十六进制字符
    └── 支持访问权限验证
```

#### **2. AI 智能验证码识别配置（推荐）**
```
🤖 AI 智能验证码识别 (统一配置)
├── AI API Key (密码)
│   ├── 支持多种服务：OpenAI、OpenRouter、其他兼容服务
│   ├── 格式：sk-... (OpenAI) 或 sk-or-v1-... (OpenRouter)
│   └── 获取地址：https://platform.openai.com 或 https://openrouter.ai
├── API 基础 URL (文本，可选)
│   ├── OpenAI 官方：留空（使用默认）
│   ├── OpenRouter：https://openrouter.ai/api/v1
│   └── 其他服务：填写相应的 API 地址
├── 模型名称 (文本输入)
│   ├── 用户可自由输入任何兼容模型名称
│   ├── 常用示例：gpt-4-vision-preview, qwen/qwen2.5-vl-72b-instruct:free
│   └── 支持所有 OpenAI Vision API 兼容的模型
├── 启用智能识别 (布尔值)
│   └── 控制是否使用 AI 智能验证码识别功能
├── 置信度阈值 (数值)
│   ├── 范围：0.0 - 1.0
│   └── 默认：0.7
└── 请求超时时间 (数值)
    ├── 单位：秒，范围：5 - 300
    └── 默认：30
```

#### **💡 简化配置方案**

**🎯 三个核心配置**
只需配置这三个参数即可适配任何兼容服务：
1. `OPENAI_API_KEY` - API 密钥
2. `OPENAI_BASE_URL` - API 地址（可选）
3. `MIDSCENE_MODEL_NAME` - 模型名称

**🆓 免费方案（推荐）**
```bash
OPENAI_API_KEY=sk-or-v1-your-key
OPENAI_BASE_URL=https://openrouter.ai/api/v1
MIDSCENE_MODEL_NAME=qwen/qwen2.5-vl-72b-instruct:free
```

**💰 付费方案（高精度）**
```bash
OPENAI_API_KEY=sk-your-openai-key
# OPENAI_BASE_URL 留空
MIDSCENE_MODEL_NAME=gpt-4-vision-preview
```

**🔧 自定义方案**
```bash
OPENAI_API_KEY=your-custom-key
OPENAI_BASE_URL=https://your-api.com/v1
MIDSCENE_MODEL_NAME=your-custom-model
```

#### **3. 验证码服务配置**
```
🛡️ 验证码服务
├── 第三方验证码 API Key (可选)
│   └── 第三方验证码识别服务
└── 启用 OCR 识别 (布尔值)
    ├── 本地 OCR 功能开关
    └── 默认：启用
```

#### **4. 应用配置**
```
⚙️ 应用配置
├── 应用端口 (数值)
│   ├── 范围：1000 - 65535
│   ├── 默认：3000
│   └── 需要重启应用
├── 日志级别 (选择)
│   ├── 选项：error, warn, info, debug
│   └── 默认：info
└── 会话超时时间 (数值)
    ├── 单位：分钟
    ├── 范围：5 - 1440
    └── 默认：30
```

#### **5. 安全配置**
```
🔒 安全配置
├── 启用 HTTPS (布尔值)
│   ├── 安全连接开关
│   └── 需要重启应用
└── JWT 密钥 (密码)
    ├── 身份验证密钥
    └── 需要重启应用
```

## 🔧 配置验证

### **支持验证的配置项**

#### **Notion API Key 验证**
- ✅ **格式检查**：验证是否以 `secret_` 开头
- ✅ **连接测试**：调用 Notion API 验证密钥有效性
- ✅ **用户信息**：显示关联的用户信息

#### **Notion 数据库 ID 验证**
- ✅ **格式检查**：验证是否为 32 位十六进制字符
- ✅ **访问权限**：检查数据库访问权限
- ✅ **数据库信息**：显示数据库名称和属性数量

#### **Midscene API Key 验证**
- ✅ **格式检查**：验证密钥格式和长度
- ✅ **连接测试**：测试 API 连接（当前为模拟模式）
- ✅ **服务状态**：显示服务可用性

### **验证操作**
1. **输入配置值**后，点击输入框右侧的 ✓ 按钮
2. **等待验证**：显示验证进度
3. **查看结果**：
   - 🟢 **验证成功**：显示绿色勾号和成功信息
   - 🔴 **验证失败**：显示红色警告和错误信息

## 💾 配置文件管理

### **自动生成的 .env.local 文件**
```env
# 环境管理器配置文件
# 此文件由配置管理功能自动生成和维护
# 最后更新时间: 2024-01-20 10:30:00

# 📝 Notion 配置
# Notion API 和数据库相关配置
NOTION_API_KEY=secret_your_api_key_here
NOTION_DATABASE_ID=your_database_id_here

# 🤖 Midscene.js 配置
# 智能验证码识别服务配置
MIDSCENE_API_KEY=your_midscene_api_key_here
MIDSCENE_ENABLED=true
MIDSCENE_CONFIDENCE_THRESHOLD=0.7

# ⚙️ 应用配置
# 应用运行相关的基础配置
APP_PORT=3000
LOG_LEVEL=info
SESSION_TIMEOUT=30
```

### **备份机制**
- **自动备份**：每次保存前自动创建 `.env.backup` 文件
- **版本安全**：`.env.local` 已在 `.gitignore` 中，不会提交到代码库
- **恢复功能**：如有问题可手动恢复备份文件

## 🔒 安全特性

### **敏感信息保护**
- **🔐 密码字段**：API 密钥等敏感信息默认隐藏
- **👁️ 可见性控制**：点击眼睛图标切换显示/隐藏
- **🛡️ 安全标识**：敏感字段显示盾牌图标
- **📝 格式验证**：防止无效配置导致安全问题

### **访问控制**
- **🔒 本地存储**：配置文件仅存储在本地服务器
- **🚫 版本控制排除**：敏感配置不会意外提交
- **🔄 重启提醒**：关键配置更改后提示重启应用

## 📊 配置状态指示

### **状态标识**
- **🟢 已配置**：配置项有值且验证通过
- **🟡 待验证**：配置项有值但未验证
- **🔴 配置错误**：配置项验证失败
- **⚪ 未配置**：可选配置项未设置
- **🔴 必需配置**：必需配置项未设置

### **更改指示**
- **🟠 待保存**：显示 "● 已修改，等待保存"
- **📊 更改计数**：页面顶部显示待保存项目数量
- **⚠️ 重启提醒**：某些配置需要重启应用才能生效

## 🚀 最佳实践

### **初次配置建议**
1. **按顺序配置**：
   - 首先配置 Notion（必需）
   - 然后配置 Midscene.js（可选，提升功能）
   - 最后调整应用和安全设置

2. **验证每个配置**：
   - 输入后立即点击验证按钮
   - 确保所有必需配置都验证通过
   - 解决任何验证错误

3. **保存和重启**：
   - 配置完成后点击"保存配置"
   - 如提示需要重启，重启应用使配置生效

### **日常维护**
- **定期检查**：定期访问配置管理页面检查状态
- **密钥轮换**：定期更新 API 密钥并重新验证
- **备份重要配置**：手动备份重要的配置文件

### **故障排除**
1. **配置验证失败**：
   - 检查网络连接
   - 确认 API 密钥有效性
   - 查看详细错误信息

2. **配置不生效**：
   - 确认已点击"保存配置"
   - 检查是否需要重启应用
   - 查看应用日志

3. **配置丢失**：
   - 检查 `.env.local` 文件是否存在
   - 使用 `.env.backup` 恢复配置
   - 重新配置丢失的项目

## 🔄 配置重置

### **重置功能**
- **完全重置**：点击"重置"按钮恢复所有默认值
- **确认机制**：重置前需要确认操作
- **自动备份**：重置前自动备份当前配置

### **重置后操作**
1. **重新配置必需项**：Notion API 和数据库配置
2. **重新验证连接**：确保所有服务正常
3. **重启应用**：使新配置生效

---

**注意**：配置管理功能会自动维护 `.env.local` 文件，请不要手动编辑此文件，以免配置丢失或格式错误。
